# Assignment 6.2 - Backgrounds, Borders & Display

## Cards

| Card | Background | Border | Border Radius |
|---|---|---|---|
| Basic | white | 2px solid grey | 12px |
| Standard | light blue | 3px solid blue | 20px |
| Premium | light yellow | 4px double orange | 30px and 6px on opposite corners |

Each card has a title, a description and a button, and all cards use width: 250px, max-width: 100% and a minimum height.

## Display Property

- block: the element starts on a new line, takes the full line, and accepts width and height. Used for the Block 1 and Block 2 examples.
- inline: the element stays in the line of text, and width and height are ignored. Used for the Inline 1, 2 and 3 examples.
- inline-block: the element stays in the line like inline, and it also accepts width and height. Used for the cards, the buttons and the Inline-block examples.

## Width, Height and Max-Width

- width sets the normal width of the element.
- height or min-height sets how tall the element is.
- max-width stops the element from becoming wider than that value, so the cards shrink on small screens.
